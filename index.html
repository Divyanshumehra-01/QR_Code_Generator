USER GUIDE & FAQ

Learn how to customize, scan, and print your brutalist QR codes.

How to Generate?

Type any text, link, email, or WiFi coordinates in the GENERATE input field. The QR code canvas will update instantly in the preview panel.

Customizing Styles & Colors

Under the CUSTOMIZE tab, click the color boxes to alter foreground and background colors. Adjust Margins and Resolution (size) using the sliders.

Center Logos & Safety Margin

You can drag and drop a custom logo image in the CUSTOMIZE logo panel. We automatically mask the center and draw a bounding border. Note: Ensure SCAN RELIABILITY is set to HIGH so the code remains readable.

SVG vs. PNG vs. PDF

Go to the PREVIEW tab to download. Use PNG for web sharing, SVG vector paths for resizing inside design software without quality loss, and PDF for high-fidelity technical printable layouts.
